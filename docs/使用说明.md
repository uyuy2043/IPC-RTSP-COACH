# 使用说明

本文说明网页教练的学习路径、每天怎么学，以及 `lab/rtsp_miniclient.py` 做什么。安装和启动见 [README.md](../README.md)。

## 学习路径

摸底之后，路线按你的基础裁剪：

- 网络选了「刚入门」，或抓包选了「没抓过包」，会先排**阶段 0**。
- 这两项都已经有底子时，从**阶段 1**开始。

各课按顺序解锁。页头会按你选的每天分钟数，把全程估成大约多少次。一课的次数是 `ceil(本课分钟数 / 每天分钟数)`，至少 1 次。和你的学习目标更相关的课会标「和你的目标更相关」。

每课正文按小节组织，常见的有：核心概念、协议报文、真实示例、抓包分析、工具命令、代码实践、IPC 厂商差异、常见坑。文中的地址会按你的摸底替换：勾了「这是我有权抓包、有权拉流的真实地址」并填了 URL 时，用你留下的地址；否则继续用教学示例。

## 日常使用

打开 [http://127.0.0.1:43123](http://127.0.0.1:43123) 之后：

1. 第一次使用先答完 7 题，最后一题点「生成我的路线」。
2. 在路线上只打开标着「当前」的那一课。已完成的课可以再打开复习；未解锁的课点不开。
3. 读完本节后做末尾 3 题。三题都选对，点「提交答案」。全对之后，「我学完了，继续」变为可点，并直接进入下一模块。
4. 有题没选对时，看解析、改选项，再提交。改选项会清掉上一次的提交结果。
5. 中途可以点「返回路线」。进度留在本机浏览器，键名 `rtsp-coach-v1`，里面有摸底、已完成的课、已通过测验的课，以及当前停在哪一屏。
6. 全部模块完成后进入「这一路走完了」。可以从那里回到路线，或点「重新评估」清空进度，重新答 7 题。

进度只在当前浏览器里。换一台电脑、换一个浏览器，或清除这个站点的本地存储，都会回到摸底。摸底里填写的型号和 RTSP 地址也会写进同一条记录，所以不要在公共电脑上留下口令。

每天能学的时长只影响路线上的次数估算，不会自动把一课拆成多页。一次坐下读不完时，关掉页面即可，下次打开会回到上次的路线或课文。

## 实验脚本

`lab/rtsp_miniclient.py` 跟阶段 12 的课对应。它只依赖 Python 3 标准库。

### 自测

```bash
python3 lab/rtsp_miniclient.py --self-test
```

自测不连网，也不打开套接字。它检查：

- Digest 的 RFC 2617 测试向量（`qop=auth`）
- 把 URL 里的口令打成 `***`
- SDP 里 `a=control` 的相对路径、绝对地址、`*` 和以 `/` 开头的路径怎么拼到会话地址上
- 一帧 RTP 固定头（版本、marker、载荷类型、序号、时间戳、SSRC）
- 一份含视频和音频的 SDP，以及视频轨的 control
- 海康通道 3 子码流路径 `/Streaming/Channels/302`（通道从 1 计，主码流个位为 1，子码流个位为 2）
- `Session` 头里的会话号和 `timeout`

成功时打印 `self-test ok`，进程退出码为 0。某一项对不上时，标准错误会写出期望值和实际值，退出码为 1。

### 现场拉流

只对你拥有或被明确授权的摄像机使用：

```bash
python3 lab/rtsp_miniclient.py --url "rtsp://user:pass@192.168.1.64:554/Streaming/Channels/101" --seconds 3
```

现场模式的顺序是：

1. 连接 URL 里的主机，端口缺省为 554，连接超时 5 秒。
2. `OPTIONS`
3. `DESCRIBE`（`Accept: application/sdp`）。若返回 401，用 URL 里的用户名和口令做 Digest，再发一次。
4. 取视频轨的 `a=control`，发 `SETUP`，传输为 `RTP/AVP/TCP;unicast;interleaved=0-1`。
5. `PLAY`，然后在 `--seconds` 秒内读取交织通道上的 RTP，打印包数、载荷类型和第一包序号。
6. `TEARDOWN`

标准输出里的地址会打码。退出码：播放得到 200 为 0；DESCRIBE、SETUP 或 PLAY 失败为 1；没有给出 `--url` 或 `--self-test` 时打印帮助并退出码 2。

### 口令

命令行里的 `rtsp://user:pass@主机/...` 会完整出现在进程列表和 shell 历史中。打印日志时的打码挡不住 `ps` 和历史记录。用完后清掉历史里的这条命令，不要把带口令的地址写进笔记或提交到仓库。
